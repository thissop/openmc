# DEFERRED — what is still placeholder / not yet modeled (Tier 8 / Part B)

Honest list of the simplifications in the 3D-field-driven stellarator tier, so a
collaborator knows exactly what a result does and does NOT support. Each item
names the code seam and the upgrade path.

## Geometry
- **Transport geometry is axisymmetric** (a layered box-torus radial-build rig),
  NOT a 3D stellarator first wall. The 3D physics is only in the SOURCE (field map
  + flux-surface births). **No field-period / QA *geometry* effect is claimed.**
  Upgrade: build a real 3D wall from the boundary Fourier fits via Stellarmesh /
  build123d → DAGMC (preferred), or a per-cross-section swept-shell CSG. Seam:
  `python/stellarator_model.py` (`_box`/`build_model`).
- **Square (box) cross-section** for the layers, not a conformal D-shape; SOL gap
  varies around the box. Seam: `stellarator_model._box`.
- **Plasma source region is circular** (`(1-ρ²)` on circular flux surfaces), not the
  real LCFS. Drops in once the boundary Fourier fits arrive (DATA_NEEDED §1). Seam:
  `shape=plasma` sampler in `src/polarized_fusion_source.cpp`.

## Field
- **Field map is a synthetic QA stand-in** (toroidal 1/R + ι poloidal + 2-FP
  cos modulation), not a real equilibrium B(x). Seam:
  `python/make_standin_field.py` (producer); the reader/format is final.
- **Field-map file format is raw little-endian f8 + text meta.** Assumes same-endian
  C++/Python platforms (true here; guarded by the parity test). Portable upgrade:
  HDF5 (already linked by libopenmc) — store `<f8` datasets, read `H5T_NATIVE_DOUBLE`.
  Seam: `src/spf_fieldmap.hpp` + `python/fieldmap.py` + `make_standin_field`.
- **Interpolation is multilinear** (clamped R/Z, periodic φ). Fine for B̂ direction;
  a higher-order scheme would be needed for derivatives. Seam: `tri()` in both.

## Source physics
- **Monoenergetic 14.1 MeV.** The Ballabio / D-D energy-broadening hook is marked
  but NOT implemented (`INJECT(helios)` in `polarized_fusion_source.cpp`); needs
  Tᵢ(ρ) profiles. Energy is decoupled from the angular physics, so this does not
  affect the steering results.
- **Reaction-rate weighting is `(1-ρ²)`**, not real n(ρ),T(ρ) profiles
  (DATA_NEEDED §6).
- **Polarization (a,b,c) is a spatially uniform input** — no depolarization during
  confinement, no spatial polarization profile.
- **Angled analytic ceiling wall** is rejected for α≠0 (up-down symmetry broken);
  the angled gate uses inboard/outboard/floor. A symmetry-aware ceiling kernel is
  deferred. Seam: `analytic_nwl._target_primitives`.

## Transport / tallies
- **Deep-coil tallies need variance reduction.** The coil sits behind ~55 cm of
  blanket+shield, so the coil fast-flux (>0.1 MeV) tally is ~25–30% MC error at
  2e6 histories — too noisy for a precise directional-η. The **resolved first-wall**
  steering and η are reported instead; a MAGIC/weight-window run (as Bae 2025)
  would resolve the coil. Seam: `stellarator_model` tallies + a Settings.weight_windows.
- **No depletion / burnup**, single-zone blanket, no coolant channels or tritium
  extraction; TBR is a production rate, not an engineering breeding ratio.
- **294 K cross sections** used with high-temperature material densities
  (temperature inconsistency; carried from Tiers 5/6).
- **Scattering steering is geometry-specific**: the ±20% free-streaming inboard
  steering dilutes to ±~2% incident at the first wall behind the thick Helios-class
  blanket (consistent with the Tier-5 ~3× dilution finding). η is computed on these
  small scattered values, so it is approximate.

## Build / infra
- **Compiled-source build requires OpenMC `make install`ed into the venv prefix**
  (`find_package(OpenMC)`); a build-tree config is not consumable.
- **Statepoints are written to ephemeral `/tmp`**; figures/metrics must be
  regenerated by re-running the `verify_*.py` scripts.

## Not deferred (done / validated)
The MagneticField interface (constant/toroidal/angled/fieldmap), C++↔Python field
bit-parity, the angled-field analytic gate vs anarrima (Part A), the field-map
reader + interp parity, and the end-to-end pipeline with its reduce-to-axisymmetric
and emission-moment anchors are all in place and tested.
